## 1. Parabole (niveau 0 - boussole)

1. Un etat **stable** (stase / cohesion extreme) hors du cadre que nous mesurons aujourd'hui.
2. Une **perturbation** (decohesion / choc) -> ce que *nous* appelons Big Bang : l'emergence de *notre* plasma, pas necessairement t = 0 de tout.
3. Tout est energie ; localement rien ne se cree, rien ne se perd, tout se transforme.
4. Nous sommes dans un **ballon** (patch causal).
5. Si un trou noir detruit de la matiere : soit elle **reste** dans le ballon, soit elle **sort** - et alors il y a un dehors / un englobant.

Amour dans ce texte = **cohesion / collaboration** (cycles fermes, interdependance), pas le sentiment humain.
Chaos / mouvement / temps = condition des **rencontres et echanges** (sans mouvement : stase ; sans regle : destruction de la complexite).

Cette analogie **n'est pas une preuve physique**. Elle motive le type de questions (fenetre etroite, anti-pyramide, cycles).

## 3. Traduction en physique connue (niveau 1)

### 3.1 Etat stable + choc -> Big Bang chaud

Correspondants possibles (aucun n'est unique) :
- Faux vide / inflaton / tunnel / reheating.
- Vide de Higgs **metastable** (analogue interne : notre vide n'est peut-etre pas le plus profond).
- Big Bang chaud = emergence de *notre* plasma apres un regime deja etendu.

### 3.2 Conservation

- **Locale** : oui (labo, collisions).
- **Globale** en expansion : l'energie n'est pas un compteur unique (pas d'invariance de Noether temporelle).
  - Photons : redshift, perte d'energie sans aller quelque part.
  - Vide / energie noire : densite ~ constante => total augmente avec le volume.

C'est un trou dur. Une energie noire *variable* (indices DESI, a confirmer) rapprocherait le vide d'un **champ** plutot que d'une constante morte.

### 3.3 Trou noir : trois issues

| Voie | Idee | Dans notre ballon ? | Testabilite |
|------|------|---------------------|-------------|
| **A** | Info / energie reemise (Hawking, iles, courbe de Page) | Oui | Theorie + analogues ; mecanisme ouvert |
| **B** | Rebond (trou blanc, etoile de Planck) | Oui | Echos GW, restes ; FRB comme origine dominante disfavorisee |
| **C** | Univers bebe / dehors du patch (Wheeler, Farhi-Guth, Smolin) | Non (pour nous) | Quasi inobservable ; tests indirects fragiles |

A et B restent dans le ballon. C est l'intuition s'il sort, quelque chose englobe - **ouverte, non conclue**.

### 3.4 Couches : hydrogene vs Higgs vs vide

| Couche | Role | Ce que ce n'est pas |
|--------|------|---------------------|
| Hydrogene | Meilleur proxy labo (raies, NIST, mu) | Pas le premier etre ni l'onde primordiale |
| Higgs | Echelle EW *avant* les atomes ; VEV ; vide metastable | Pas une onde cosmique unique |
| Vide / Lambda / champ | Candidat le plus proche d'un fond cosmique | Pas identifie a Amour |

Chronologie : Higgs/EW (~10^-12 s) -> nucleons -> atomes H (~3,8e5 ans).
Chercher une frequence d'onde de Higgs au sens d'une raie spectrale confond **echelle d'energie** et **oscillation observable**.
